# Сварщик с нуля — Дизайн-документ (MVP)

**Дата:** 2026-04-11  
**Статус:** Утверждён  
**Стек:** Vue 3 + Vite + TypeScript + Capacitor  
**Целевые платформы:** Web (primary), iOS, Android (через Capacitor)

---

## 1. Концепция

Интерактивное веб-приложение для обучения сварке по российским ГОСТ-стандартам. Любой человек — с нуля — может пройти путь от "что такое сварка" до уверенного выполнения базовых швов.

**Целевая аудитория:**
- Полные новички (основной поток)
- Люди с начальным опытом (могут пропустить нулевой модуль)

**Дух приложения:** Индустриальное / профессиональное. Тёмная тема, красные акценты, технический шрифт — ощущение взрослого справочного инструмента, а не детской игры.

**Цветовая схема:**
- Фон: `#1a1a2e`
- Карточки/панели: `#16213e`
- Акцент: `#e94560`
- Текст основной: `#e2e2e2`
- Текст вторичный: `#8b949e`
- Ссылки/интерактив: `#58a6ff`

## 3. Структура контента (MVP)

### Модуль 0 — Азы сварки *(пропускаемый)*

1. Что такое сварка и как она работает (физика процесса)
2. Виды сварки: РДС, МИГ/МАГ, TIG — когда что применяется
3. Техника безопасности — требования по ГОСТ 12.3.003-86
4. **Тест-допуск** — обязателен для разблокировки Модуля 1

### Модуль 1 — Оборудование

1. Сварочный инвертор: характеристики и настройка
2. Средства защиты: маска (классы затемнения), перчатки, спецодежда
3. Электроды: маркировка по ГОСТ 9467-75, как выбрать
4. **Тест** по теме модуля

### Модуль 2 — Первый шов

1. Подготовка металла: зачистка, разделка кромок (ГОСТ 5264-80)
2. Режимы тока: зависимость от толщины металла и типа стыка
3. Техника ведения электрода: угол, скорость, дуга
4. Типичные дефекты новичка и как их избежать
5. **Найди дефект** — интерактивная задача

### Раздел "Снаряжение"

Статический контент (TypeScript), ориентирован на российский рынок.

- Минимальный стартовый комплект
- Как выбрать инвертор (на что смотреть: ПВ%, ток, вес)
- Как выбрать маску (класс затемнения, время срабатывания)
- Как выбрать электроды (марки для начинающих: УОНИ, АНО)
- Ценовые диапазоны: бюджетно / нормально / профи
- Ссылки: Ozon, Wildberries, ВсеИнструменты.ру, локальные сварочные магазины
- Что брать сразу, что можно докупить потом

### Раздел "О приложении / Источники"

- Список ГОСТ-стандартов (см. секцию 7)
- Учебная литература (см. секцию 7)
- Дисклеймер: приложение не заменяет практику под руководством мастера

## 4. Интерактивные элементы

### Тесты с анимацией ошибок

После каждого урока — 3–5 вопросов с одним правильным ответом.

- Правильный ответ: зелёная анимация + краткое подтверждение
- Неправильный ответ: красная анимация + объяснение **что происходит если так делать** (текст или SVG-схема)
- Порог прохождения: 80%. При провале — повтор с перемешанными вопросами
- Результат сохраняется в localStorage

### Найди дефект

Отображается изображение сварного шва (SVG или фото). Пользователь кликает на область дефекта.

- Активные зоны заданы координатами в TypeScript-конфиге
- При правильном клике: подсветка + название дефекта по ГОСТ + объяснение причины
- Классификация дефектов по ГОСТ 30242-97
- MVP: 5–8 задач с разными типами дефектов (поры, подрезы, непровары, кратеры)

### Калькулятор режимов

Интерактивный инструмент всегда доступен через вкладку "Инструменты".

Входные параметры:
- Толщина металла (мм)
- Тип сварного соединения (стыковое, угловое, нахлёсточное)
- Тип электрода (марка)

Выходные параметры (по ГОСТ 5264-80):
- Диаметр электрода (мм)
- Сварочный ток (А) — диапазон
- Количество проходов

Логика расчёта — таблицы из ГОСТ, хардкодированные в TypeScript.

## 5. Модель данных

```typescript
// Шаг урока — может быть теорией, тестом или интерактивом
type Step =
  | { type: 'theory'; blocks: ContentBlock[]; sources: SourceRef[] }
  | { type: 'quiz'; questions: Question[]; passingScore: number }
  | { type: 'defect-challenge'; challengeId: string }

type Question = {
  text: string
  options: string[]
  correctIndex: number
  errorExplanation: string  // показывается при неверном ответе
  sources: SourceRef[]
}

type Lesson = {
  id: string
  title: string
  moduleId: string
  steps: Step[]
  sources: SourceRef[]
}

type Module = {
  id: string
  title: string
  description: string
  skippable: boolean      // true только для Модуля 0
  lessons: Lesson[]
  unlockedBy: string[]    // id модулей, которые должны быть завершены
}

type SourceRef = {
  label: string           // "ГОСТ 5264-80 п.3.2"
  url?: string            // ссылка на docs.cntd.ru если доступна
}
```

### Состояние в localStorage

```typescript
type AppProgress = {
  onboardingDone: boolean
  experienceLevel: 'beginner' | 'experienced'
  completedLessons: string[]         // массив lesson.id
  completedModules: string[]         // массив module.id
  quizScores: Record<string, number> // lessonId → процент правильных ответов
  lastVisited: string                // route
}
```

Ключ в localStorage: `welding-app-progress`. Структура намеренно плоская — при добавлении бэкенда маппится 1:1 на таблицы БД.

## 7. Источники и литература (для раздела /about)

### ГОСТ-стандарты

- **ГОСТ 5264-80** — Ручная дуговая сварка. Соединения сварные. Основные типы, конструктивные элементы и размеры
- **ГОСТ 9467-75** — Электроды покрытые металлические для ручной дуговой сварки конструкционных и теплоустойчивых сталей
- **ГОСТ 12.3.003-86** — ССБТ. Работы электросварочные. Требования безопасности
- **ГОСТ Р ИСО 4063-2010** — Сварка и родственные процессы. Перечень и условные обозначения процессов
- **ГОСТ 30242-97** — Дефекты соединений при сварке металлов плавлением. Классификация, обозначение и определения

### Учебная литература

- Виноградов В.С. — *Оборудование и технология дуговой автоматической и механизированной сварки*
- Куликов В.П. — *Технология сварки плавлением*
- Алёшин Н.П., Щербинский В.Г. — *Контроль качества сварочных работ*

### Открытые источники

- docs.cntd.ru — электронный фонд правовых и нормативно-технических документов

> **Дисклеймер:** Приложение создано в образовательных целях и не заменяет практическое обучение под руководством квалифицированного сварщика. Перед началом сварочных работ необходимо пройти инструктаж по технике безопасности.

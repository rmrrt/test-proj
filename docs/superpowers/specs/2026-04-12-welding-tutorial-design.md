# Welding Tutorial — Design & Architecture Spec
_Дата обновления: 12 апреля 2026_

---

## 1. Обзор проекта

Мобильный интерактивный туториал по ручной дуговой сварке (РДС) для русскоязычной аудитории. Vue 3 SPA, адаптирован под телефон, ориентирован на практика — не на теоретика.

**Целевая аудитория:**
- Полные новички — основной поток
- Люди с начальным опытом, желающие систематизировать знания

**Дух приложения:** Индустриальное, взрослое, профессиональное. Тёмная тема, красные акценты — ощущение справочного инструмента мастера, а не обучающей игрушки.

**Язык:** Русский. Нормативная база — российские ГОСТ.

## 3. Архитектура контента

### Модель данных

```
Module → Lesson → Step[]
```

```typescript
type Step =
  | { type: 'theory'; blocks: ContentBlock[]; sources?: SourceRef[] }
  | { type: 'quiz'; questions: Question[]; passingScore: number }
  | { type: 'defect-challenge'; challengeId: string }

type Lesson = {
  id: string
  title: string
  moduleId: string
  durationMin: number
  steps: Step[]
  sources?: SourceRef[]
  videos?: VideoRef[]
  practicalNote?: { summary: string; examples?: string[] }
}

type Module = {
  id: string
  title: string
  description: string
  icon: string
  skippable: boolean
  lessons: Lesson[]
  unlockedBy: string[]   // цепочка зависимостей между модулями
}
```

### Правила контента

- Квиз: 3 вопроса на урок, порог прохождения — **80%**. При провале — повтор.
- Каждый урок имеет `practicalNote` — краткий вывод "что это значит для сварщика на практике" с 2–3 примерами.
- Каждый урок имеет 2 видео: YouTube + RuTube (для аудитории с ограниченным доступом к YouTube).
- Источники (`sources`) ссылаются на конкретные ГОСТ на docs.cntd.ru.

### Хранилище прогресса

Pinia store (`src/stores/progress.ts`) → localStorage, ключ `welding-app-progress`.

```typescript
type AppProgress = {
  onboardingDone: boolean
  experienceLevel: 'beginner' | 'experienced'
  completedLessons: string[]
  completedModules: string[]
  quizScores: Record<string, number>   // lessonId → доля правильных ответов
  lastVisited: string
}
```

Структура плоская — при добавлении бэка маппится 1:1 на таблицы БД.

## 5. Инструменты

Доступны через вкладку «Инструменты» без прохождения уроков.

### ModeCalculator — Калькулятор режимов РДС

Логика в `src/content/tools/mode-calculator.ts` — таблицы по ГОСТ 5264-80 + коэффициенты.

**Входные параметры:**

| Параметр | Значения |
|---|---|
| Толщина металла | 1–12 мм |
| Тип соединения | butt / corner / lap (стыковое / угловое / нахлёсточное) |
| Тип металла | carbon / low_alloy / stainless / aluminum |
| Положение сварки | flat / horizontal / vertical / overhead |
| Покрытие электрода | rutile / basic |

**Выходные параметры:** диаметр электрода (мм), ток (А), количество проходов, полярность, скорость сварки (мм/с), рекомендуемая марка электрода, доп. рекомендации (предподогрев).

---

### DefectChallenge — Найди дефект

SVG-тренажёр по ГОСТ 30242-97. Пользователь кликает на область дефекта на изображении шва.

- Активные зоны определены координатами в `src/content/tools/defect-challenges.ts`
- При правильном клике: подсветка + название дефекта по ГОСТ + объяснение причины
- Встраивается в уроки как `step: { type: 'defect-challenge', challengeId }`

---

### WeldingChecklist — Готовые чеклисты

4 встроенных чеклиста:

- Первая сварка
- Сварка на улице
- Нержавейка
- Сварка трубы

---

### CustomChecklistView + ChecklistListView — Кастомные чеклисты

Создание и хранение собственных чеклистов пользователя.

**Режимы:**
- **use** — чекбоксы, счётчик прогресса, кнопка сброса
- **edit** — drag-and-drop переупорядочивание, добавление/удаление пунктов

**AI-генерация:** замокана, работает в демо-режиме с плашкой `⚠️ ДЕМО — подключи API`. Сигнатура метода готова к подключению реального API.

## 6. Раздел снаряжения

7 категорий, каждая — 3 ценовых тира (бюджет / средний / про) с конкретными примерами, ценами и ссылками на Ozon, Wildberries, ВсеИнструменты.ру.

| Категория | Особенности |
|---|---|
| Сварочный инвертор | ПВ%, ток, вес, бренды по тирам |
| Сварочная маска | DIN-класс, скорость срабатывания |
| Электроды | Таблица марок с типом и применением (МР-3, АНО-21, УОНИ-13/55, ОЗЛ-8, ОЗА-1/2) |
| Защитная одежда | Материалы (спилок, брезент, хлопок) |
| Инструмент подготовки кромок | Болгарка → фаскосниматель → электрический инструмент |
| Вспомогательный инструмент | Магнитные угольники, струбцины, центраторы |
| Средства контроля шва | УШС-3, щупы, штангенциркуль → профилометр, УЗ-толщиномер |

Минимальный стартовый комплект выделен отдельной карточкой (~7 000–12 000 ₽).

## 7. Сервисный слой и хранилище

### checklistService.ts

`src/services/checklistService.ts` — абстракция хранилища кастомных чеклистов.

Все методы **async**, сигнатуры не изменятся при переходе на API:

```typescript
getAll(): Promise<Checklist[]>
getById(id: string): Promise<Checklist | undefined>
save(checklist: Checklist): Promise<void>
delete(id: string): Promise<void>
```

Текущая реализация — localStorage, ключ `weld-checklists`. В теле каждого метода — TODO-комментарий с ожидаемым REST-эндпоинтом.

### Прогресс пользователя

Pinia store (`src/stores/progress.ts`) → localStorage `welding-app-progress`. Готов к миграции на бэк.

## 8. Dev-режим

**Активация:** добавить `?dev=true` в URL → флаг сохраняется в localStorage (`welding-dev-mode`). Страницу можно перезагружать.

**Composable:** `src/composables/useDevMode.ts`

**Эффекты:**
- Все модули и уроки разблокированы (игнорируется `unlockedBy`)
- В квизах правильный ответ подсвечивается зелёной рамкой со значком ✓ до ответа пользователя
- Красный бейдж **DEV** в правом нижнем углу экрана

**Деактивация:** удалить ключ из localStorage или открыть в инкогнито без `?dev=true`.

## 10. UI/UX принципы

**Цветовая схема:**

| Токен | Значение |
|---|---|
| Фон | `#1a1a2e` |
| Карточки/панели | `#16213e` |
| Акцент | `#e94560` |
| Текст основной | `#e2e2e2` |
| Текст вторичный | `#8b949e` |
| Ссылки/интерактив | `#58a6ff` |

**Навигация:** 5 вкладок — Модули / Инструменты / Снаряжение / Прогресс / О приложении.

**Структура урока (порядок):**
1. Теория — markdown-блоки, блоки `warning`, SVG-диаграммы
2. Видео — карточки YouTube + RuTube
3. `practicalNote` — блок «💡 Что это даёт на практике»
4. Квиз — 3 вопроса, 80% для прохождения

**Онбординг:** показывается при первом запуске. Развилка «Я новичок / Уже варил» → определяет начальное состояние прогресса.

**Вёрстка:** mobile-first, все компоненты рассчитаны на экран телефона.

## 11. Источники и нормативная база

| ГОСТ | Тема |
|---|---|
| ГОСТ 5264-80 | Ручная дуговая сварка. Типы соединений, конструктивные элементы |
| ГОСТ 9467-75 | Электроды покрытые. Классификация и маркировка |
| ГОСТ 12.3.003-86 | Электросварочные работы. Требования безопасности |
| ГОСТ 30242-97 | Дефекты сварных соединений. Классификация |
| ГОСТ 2.312-72 | Обозначения сварных швов на чертежах |
| ГОСТ Р ИСО 4063-2010 | Сварочные процессы. Перечень и условные обозначения |
| ГОСТ 14771-76 | Сварка в защитных газах. Типы соединений |

**Учебная литература:**
- Виноградов В.С. — *Оборудование и технология дуговой автоматической и механизированной сварки*
- Куликов В.П. — *Технология сварки плавлением*
- Алёшин Н.П., Щербинский В.Г. — *Контроль качества сварочных работ*

> **Дисклеймер:** Приложение создано в образовательных целях и не заменяет практическое обучение под руководством квалифицированного сварщика.
